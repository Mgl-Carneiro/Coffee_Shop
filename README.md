# ☕ Cafeteria

Bem-vindo ao projeto Cafeteria! Este é um site desenvolvido para representar uma cafeteria moderna, apresentando alguns produtos, informações e uma interface agradável e intuitiva. O principal objetivo deste projeto é colocar em prática conhecimentos de desenvolvimento web, trabalhando com estrutura HTML, estilização CSS e funcionalidades JavaScript.

### Sobre o projeto

O projeto foi criado utilizando HTML, CSS e JavaScript, com o objetivo de desenvolver uma página web de cafeteria moderna, responsiva e fácil de navegar.

A proposta é apresentar uma experiência visual agradável para os visitantes, destacando os cafés, produtos e informações da cafeteria.

## Tecnologias utilizadas

- HTML5 — Estrutura da página
- CSS3 — Estilização e responsividade
- JavaScript — Interatividade e funcionalidades

## Design

O projeto utiliza uma identidade visual inspirada em cafeterias, com cores e elementos que remetem ao café e proporcionam uma aparência moderna e aconchegante.
